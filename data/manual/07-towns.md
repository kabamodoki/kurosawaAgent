# 黒澤クエスト マニュアル 07: 町と施設

## 主な町
| 町 | 場所 | 特徴 |
|----|------|------|
| 黒澤村 | 国の中央 | 最初の拠点。沢神社と冒険者ギルドの本部がある |
| 霧見の宿場（きりみのしゅくば） | 北の峠 | 宿屋が安い。北の沼地へ向かう前に寄る町 |
| 澄川の港（すみかわのみなと） | 東の河口 | 釣り師の道具がそろう。舟で離れ島へ渡れる |

## 施設
| 施設 | できること |
|------|-----------|
| 宿屋 | 泊まるとHPと気力がすべて回復する。料金は町ごとに違う（黒澤村は1泊20ゴールド、霧見の宿場は1泊12ゴールド） |
| 道具屋 | アイテムの売り買い |
| 武器屋 | 武器と防具の売り買い |
| 沢神社 | 冒険の記録（セーブ）、職業の変更、お祓い（濁り度を0にする。無料） |
| 冒険者ギルド | 依頼（クエスト）の受注・登録・報告 |
