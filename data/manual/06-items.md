# 黒澤クエスト マニュアル 06: アイテム

| アイテム | 効き目 | 道具屋での値段 |
|---------|-------|---------------|
| やくそう | HPを30回復する | 8ゴールド |
| 上やくそう | HPを100回復する | 30ゴールド |
| どくけし | 毒を治す | 10ゴールド |
| 澄み水 | 濁り度を30下げる | 25ゴールド |
| たいまつ | 暗い洞くつを10分間照らす | 5ゴールド |
| 帰り羽 | 最後に立ち寄った町へ戻る | 40ゴールド |
| 気つけ団子 | 倒れた仲間を、HPが半分の状態で起こす | 60ゴールド |

## 持ち物のルール
- 同じアイテムは、1種類につき99個まで持てます。
- 道具屋で売ると、買った値段の半分のゴールドになります。
- 在庫の数は道具屋によって違います。
