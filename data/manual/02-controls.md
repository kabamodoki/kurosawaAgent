# 黒澤クエスト マニュアル 02: 操作方法

| 操作 | キーボード | ゲームパッド |
|------|-----------|-------------|
| 移動 | 矢印キー または WASD | 左スティック |
| 決定・調べる・話す | Enter または Z | Aボタン |
| キャンセル | Esc または X | Bボタン |
| メニューを開く | M | Yボタン |
| ダッシュ（押している間） | Shift | Rボタン |
| 地図を開く | Tab | Selectボタン |

## ヒント
- 光っている場所を「調べる」と、アイテムが見つかることがあります。
- 町の中ではダッシュできません。
- 操作は「メニュー」→「設定」→「操作の割り当て」で変えられます。
