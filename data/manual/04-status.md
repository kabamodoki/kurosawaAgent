# 黒澤クエスト マニュアル 04: ステータスの見方

| 項目 | 意味 |
|------|------|
| HP | 体力。0になると倒れる |
| 気力 | 技や術を使うと減る。宿屋に泊まると回復する |
| 力 | 攻撃の強さ |
| 守り | 受けるダメージの減りやすさ |
| 素早さ | 戦闘で行動する順番の早さ |
| 運 | 会心の一撃や、宝箱の中身のよさに関わる |
| 濁り度 | 0〜100。墨の属性の攻撃を受けると上がる |

## 濁り度と「墨化（すみか）」
- 濁り度が100になると「墨化」の状態になり、毎ターンHPが減って、技が使えなくなります。
- 濁り度は、次のどれかで下げられます。
  - アイテム「澄み水」を使う（濁り度が30下がる）
  - 薬師の術「清め」を受ける
  - 沢神社でお祓いを受ける（無料。濁り度が0になる）
